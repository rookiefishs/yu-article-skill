# Prompt Examples

## 1. 没指定输出形式，默认长文

```text
用 yu-article-skill 帮我做一个主题：为什么很多人用 Claude Code 做长任务会跑偏。
我没有指定输出形式，请按默认长文流程先给预览，再生成长文目录。
```

## 2. 指定长文

```text
用 yu-article-skill 写一个长文。
标题是：为什么很多人用 Claude Code 做长任务会跑偏
先给我预览，再按长文目录结构输出。
```

## 3. 指定图文

```text
用 yu-article-skill 写一个图文。
标题是：新手刚开始用 Skills，先装这 3 个就够了
按图文规则输出正文、配图提示词目录和 image 目录，其中封面提示词只放在 配图提示词/封面提示词.md，不要再单独生成根目录封面提示词文件。
注意图文开头介绍不要太长，开头不要加标题和序号，从后面的要点再开始编号。
每一段也不要写太满，节奏参考现有内容库里更短更直接的写法。
```

## 4. 长文或图文需要配图

```text
用 yu-article-skill 写一个图文。
标题是：Claude Code 干活更稳的 5 个习惯
正文里需要配图，请额外生成 配图提示词/ 目录。
封面提示词放在 配图提示词/封面提示词.md，所有正文配图提示词合并到 配图提示词/配图提示词.md。
不要再保留根目录封面提示词文件。
同时把默认配图参考图放进 配图提示词/配图参考图.png。
封面参考图也放进 配图提示词/封面参考图.png。
开头不要加标题和序号，从后面的要点再开始编号。
```

## 5. 指定视频，使用默认风格

```text
用 yu-article-skill 做一个视频选题。
标题是：0 代码基础的人，怎么用 AI 做出第一个能卖的东西
我没有指定视觉方向，请直接使用默认视频规范并先生成 4 秒预览。
```

## 6. 视频使用默认 DESIGN.md

```text
用 yu-article-skill 做一个视频。
标题是：Claude Code 提效与减少出错的几个关键命令
视频风格用默认。
请读取默认 DESIGN.md，再生成大纲、配音文件、素材清单和视频工程目录。
```

## 7. 使用视频模板快速制作

```text
用 yu-article-skill 做一个视频。
标题是：XXX 主题
视频风格用默认。
请基于 video-template 模板，生成 SCENES、配音文件和视频工程。
最终视频放文章根目录，命名为当前主题；DESIGN、大纲、配音文件放入素材文件。
```

## 8. 基于已有内容制作视频

```text
用 yu-article-skill 把这个图文转成视频：待-XXX标题
参考 video-production-workflow.md 的拆页规范，
把内容拆成 5-8 个场景，每个场景控制在 8-15 秒。
```
