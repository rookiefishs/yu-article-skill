# 封面提示词规则

## 目标
封面提示词是给整篇内容做封面图，不是给正文段落做辅助插图。

## 默认参考资源
- `assets/cover-reference/封面图.png`

## 执行原则
- 默认基于参考图做调整
- 不要从零重新设计一张全新海报
- 保持原图光照、颜色、布局、构图、主体姿态和整体氛围
- 重点只改标题、小字、界面信息

## 建议结构
- 用途
- 提示词
- 具体要求
- 补充约束

## 不要这样写
- 不要写成“重新设计一张海报”
- 不要大改配色
- 不要大改构图
- 不要把正文配图要求混进封面提示词里

## 自检
- 有没有明确是基于参考图调整
- 有没有保留原本风格和氛围
- 有没有只替换必要文案和信息层
