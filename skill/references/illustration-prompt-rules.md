# 正文配图提示词规则

## 目标
正文配图提示词用于生成辅助说明某一段内容的图片，不是整篇内容封面。

## 文件结构

### 图文
图文场景下，所有正文配图提示词合并到一个文件：

- `配图提示词/`
  - `封面提示词.md`
  - `配图提示词.md`
  - `配图参考图.png`
  - `封面参考图.png`

其中：
- `封面提示词.md` 用于整篇图文的封面图
- `配图提示词.md` 包含所有段落的配图提示词，一个文件搞定
- 图文场景下，封面提示词和正文配图提示词统一放在 `配图提示词/` 目录内

### 长文
长文场景下，仍然使用：

- `标题-配图提示词.md`

## 图文数量约束
- 每一段都配一张图，包括开头段
- 一张配图对应一个段落的核心内容
- 所有段落的配图提示词写在同一个 `配图提示词.md` 中

## 默认参考图
- 默认配图参考图放在 skill 内：
  - `assets/illustration-reference/配图参考图.png`
- 默认封面参考图放在 skill 内：
  - `assets/cover-reference/封面参考图.png`
- 生成图文目录时，同时复制到当前内容目录：
  - `配图提示词/配图参考图.png`
  - `配图提示词/封面参考图.png`
- 这两张图都只作为风格参考，不复制其中的具体文案和内部结构

## 图片尺寸
- 正文配图必须按上传图 1 的尺寸生成：`2048 x 1093`
- 配图提示词中必须明确写出尺寸要求：`图片尺寸：2048 x 1093`
- 不要把封面图尺寸用于正文配图

## 图文配图提示词文件格式
`配图提示词.md` 使用以下固定结构，将所有段落内容集中写在一个文件里：

```md
根据上传的图片风格，以及下面的详细内容，每一段生成一个同样风格，但是内部结构不一样的图片。
图片尺寸：2048 x 1093。
图片中不需要序号。
能使用简单表达出来的，尽量不要出现大段的文字。
注：需要生成多张照片

第一段内容原文

第二段内容原文

第三段内容原文

...
```

其中：
- 提示词头部是固定骨架，不要改动
- 每个段落的内容直接放该段正文原文，不改写、不概括
- 段落之间用空行分隔
- 不需要加”对应段落：”、”图片文件名：”等标注

## 图文默认提示词口径
图文场景下，`配图提示词.md` 默认只使用以下固定提示词骨架，后面跟各段落原文：

---

根据上传的图片风格，以及下面的详细内容，每一段生成一个同样风格，但是内部结构不一样的图片。
图片尺寸：2048 x 1093。
图片中不需要序号。
能使用简单表达出来的，尽量不要出现大段的文字。
注：需要生成多张照片

---

默认不要再额外补”补充风格约束”这类附加段落。
只有在用户明确要求统一风格、指定角色元素、指定配色或指定构图约束时，才额外追加补充说明。

## 长文数量约束
- 默认最多保留 2 张正文配图
- 只保留最值得画出来的 1 到 2 个点
- 不要为了显得完整硬拆太多图

## 执行原则
- 图文场景下，封面提示词放在 `配图提示词/封面提示词.md`
- 图文场景下，所有段落的配图提示词合并写在 `配图提示词/配图提示词.md` 一个文件中
- 图文默认提示词只保留基础骨架，不自动追加补充风格约束
- 正文配图提示词必须包含尺寸：`图片尺寸：2048 x 1093`
- 每张图的构图必须根据该段语义动态生成，不套模板
- 每张图的内部结构必须不同
- 图片里不要序号
- 尽量少字，只允许极少关键词标签
- 不要大段文字
- 段落内容直接使用原文，不要改写、概括或重新描述
- 内容要贴近对应段落，不要写成封面风格

## 自检
- 图文场景下，是否生成了 `配图提示词/封面提示词.md`
- 图文场景下，是否生成了 `配图提示词/配图提示词.md`（单文件，包含所有段落）
- 配图提示词文件是否使用了固定骨架开头
- 配图提示词文件是否明确写了 `图片尺寸：2048 x 1093`
- 是否把 skill 内置 `配图参考图.png` 与 `封面参考图.png` 放进当前 `配图提示词/`
- 正文里是否没有出现图片文件名映射
- 有没有和封面图写混
- 有没有控制文字量
- 有没有按段落内容写清楚图中要表达什么
- 图文场景下，是否每段都有配图内容
- 长文场景下，是否控制在 2 张以内
