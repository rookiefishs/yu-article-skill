# 默认视频设计（skill 默认）

## 总体方向
- 风格默认使用 **温暖纸感 / editorial / Claude 风格**，不是冷色信息图风格。
- 统一使用一套页面壳（scene shell）、顶部 meta-bar、底部 caption/progress 结构。
- 页面之间默认使用 **整页横向 push / slide 过渡**。
- 下一页进入时必须是 **完整页面整体覆盖**，不能出现“新内容浮在旧页面上方替换”的感觉。

## 默认颜色
- 页面底色：`#f5f4ed`
- 浅层背景：`#faf9f5`
- 深一点的暖边界：`#f0eee6`
- 主文字：`#141413`
- 次文字：`#5e5d59`
- 强调色：`#c96442`
- 辅助强调：`#d97757`
- 环境氛围可少量使用柔和蓝 / 绿光斑，但只能作为背景气氛，不要抢主体。

## 页面结构
每一页默认都保持统一骨架：
1. 整页背景（opaque，不透明）
2. `scene-shell` 页面壳
3. 顶部 `meta-bar`
4. 中部标题区（kicker / title / accent）
5. 配图区或信息卡片区
6. 底部 caption
7. 底部 progress bar

要求：
- 所有正文页尽量使用同一页面模板，只替换文案和配图。
- 不要每页换完全不同的布局语言。
- 即使不同 `kind`，也只是在卡片内部结构上变化，不改整页骨架。

## 过渡动画规范
- 默认过渡是 **页面整体移动**，不是逐元素换页。
- 当前页退出：整体向左推出。
- 下一页进入：整体从右侧滑入并完全覆盖当前页。
- 进入/退出时保持页面本体不透明，避免露出上一页残影。
- 不再默认使用 `clip-path` 开页、shutter bar、上下遮挡条等旧方案。

## 动效节奏
- 首屏可保留轻微 intro 动画。
- 正文页内元素可以有轻量淡入/位移，但它们只是辅助，主过渡必须是整页过渡。
- 不要做过多 stagger，避免视觉抖动。
- 保持节奏稳定、克制、像翻阅一组统一设计的页面。

## 配图规则
- 配图默认放在正文页中下部，使用统一容器。
- `object-fit: contain`
- 图片容器圆角、边框、阴影保持一致。
- 不因为单页素材不同就改变容器风格。

## 不要这样做
- 不要回到浅蓝浅绿信息图主风格
- 不要把换页做成“旧页面不动，新内容替换进去”
- 不要在换页过程中让上一页突然漏出来
- 不要每页都换一套完全不同的布局
- 不要为了炫技叠太多元素级过渡
