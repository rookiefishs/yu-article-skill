# 默认视频设计规范（skill 默认）

## 总体方向
- 风格：浅色、简约、轻设计感
- 版式：统一页面壳 + 统一 meta-bar + 统一底部字幕条 + 统一进度条
- 转场：整页横向 push / slide，下一页完整覆盖上一页
- 目标：稳定、干净、可复用，不要每次都重新试样式

## 画布
- 尺寸：1080 x 1920
- 比例：9:16
- 帧率：24fps

## 主体卡片
- 主体卡片外边距：100px
- 对应元素：
  - intro-panel
  - scene-shell
- 圆角：大圆角
- 边框：浅蓝灰边框，清晰但不过重
- 阴影：柔和双层阴影

## 颜色
- 页面背景：浅灰蓝 / 浅蓝渐变
- 主体卡片：浅蓝白底 + 很轻的浅紫辅助氛围
- 主文字：深灰近黑
- 次文字：中灰蓝
- 紫色：只作辅助高光，比蓝色更克制
- 可允许极轻的粉色点缀，但不能抢主视觉

## 视觉禁区
- 不要大片纯白发空
- 不要高饱和霓虹色
- 不要信息图风蓝绿大拼贴
- 不要 clip-path / shutter bar 主导转场
- 不要旧页不动、新内容替换式切页
