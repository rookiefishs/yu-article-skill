# Prompt Examples

## 1. 生成一整套内容目录

```text
用 yu-article-skill 写一个新选题。
标题是：为什么很多人用 Claude Code 做长任务，做着做着就会跑偏
按内容策划目录格式输出：README、长文、纯正文、发布文案、封面提示词。
```

## 2. 只改长文风格

```text
用 yu-article-skill 改写这篇长文。
不要改核心信息，只把语气、结构、节奏收回到当前这套写法。
顺手清掉模板味重的句式。
```

## 3. 生成标题

```text
用 yu-article-skill 给这个主题出 5 个标题。
要求更贴近现有内容库前 20 篇的标题风格。
```

## 4. 补齐缺失文件

```text
用 yu-article-skill 检查这个目录缺什么文件。
如果缺 README、发布文案、封面提示词，就按现有格式补齐。
```

## 5. 只做 README 策划

```text
用 yu-article-skill 先写 README。
我现在还不想写正文，只要主题定位、目标读者、表达方向、当前素材、当前状态、后续建议。
```
